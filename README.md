## About me

I'm a software developer who has been building things professionally since 2021, and I run my own software development business. Most of my work revolves around **C# and .NET**, with a strong focus on e-commerce platforms. I also have hands-on experience with C+&#8288;+, Java and Python.

I care about code that is **clean, robust and easy to maintain** — the kind you can come back to after six months and still understand.

## What I'm into

- 🧩 **Functional ideas in C#** — immutability, explicit error handling, making illegal states unrepresentable
- 🧪 **Testing & design** — TDD, small focused units, clear boundaries between commands and queries
- 🏗️ **Software architecture** — simple, evolvable designs over clever ones
- 🤖 **AI & algorithms** — exploring how they can be applied in practice, and building tools for my own use
- 📦 **Open source** — sharing small, useful libraries and learning in public
